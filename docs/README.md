# 产品与交付资料入口

| 文件 | 职责与使用方式 |
| --- | --- |
| [PRD.md](PRD.md) | 原始 MVP 需求及验收依据，保留来源；未实现的目标不能标为已完成 |
| [需求变更.md](需求变更.md) | 本会话用户确认补充、范围变化、当前差距与待确认事项 |
| [DEPLOYMENT.md](DEPLOYMENT.md) | 当前源码运行、构建、部署、云服务和备份说明，人类交付正文 |
| [技术文档.md](技术文档.md) | 历史设计方案；SQLite 等旧建议不作为当前运行事实 |
| [优秀代码风格.md](优秀代码风格.md) | 通用风格来源与示例；现行项目约定在 .agents/coding.md |
| [更新](更新) | 历史操作材料，非现行配置来源 |
| [待做.md](../待做.md) | 用户维护的待办与操作记录，不把待办描述当作已授权功能实现 |

工程事实与 Agent 规则见 [工程索引](../.agents/README.md)。新需求材料保留原件，确认后同步需求变更、验收项和受影响专题；尚未确认的取舍记录来源、影响及解除条件。不会为整理文档而删除原始 PRD 或历史设计正文。
