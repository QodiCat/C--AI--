## 2026-11-08 天气提供方切换为高德地图
来源：用户反馈“获取天气的 API 不稳定，用高德地图的 API”。替代 2026-10-05 实现的 Open-Meteo 提供方，继续自动定位和生成今日搭配，不恢复手动天气输入；原 PRD 的早期手动天气描述保留为历史来源。
验收：后端使用高德 Web 服务 Key 完成 GPS 坐标转换、行政区解析与实况/预报查询；天气和 AI 上下文取真实字段，展示当前/日夜温度及风向/风力等级，标明高德来源；不把高德未提供的体感、风速或极值伪造为测量值。失败可重试，缺少 Key/权限/额度等失败不生成 AI 搭配；Key 仅后端保存，不回传或打印。
范围：天气字段契约同步变更，需同时更新前后端；无数据库结构或依赖变更，不自动部署。缺少真实高德 Key，目前只能自动化验证，真实联通性和稳定性待配置后验收；配置步骤见 DEPLOYMENT.md。

## 2026-11-14 衣物自定义标签统计
来源：用户要求在已有自定义标签基础上增加每个标签对应的衣物件数。
- 入口：我的衣橱右上角设置 → 自定义标签统计，按件数降序，同件数按标签名称排序；显示全部衣物、未设置标签及每个标签的件数。
- 口径：按当前类型、季节、搜索及账号显示设置限定范围，忽略当前已选标签；含归档、不含已丢弃。一件衣物的相同标签去除首尾空格后只计一次，空白标签不计；一件衣物可以属于多个标签，各标签件数之和可能超过衣物总数。
- 操作：点击统计行精确筛选标签或未设置标签；点击全部衣物、删除筛选标签或重置筛选可清除标签筛选。临时标签选择不跨页面持久化；编辑、删除和新增返回时沿用衣橱重新加载，统计随最新数据更新。
- 验收：统计与筛选数量一致、重复/多标签/空标签处理、显示设置与搜索叠加、编辑返回更新、加载失败不展示虚假零值及重试、320 像素窄屏和多标签滚动。
- 当前已实现并通过自测，尚未部署或客户验收。复用 GET /items 本人数据，不新增接口或数据库迁移；原始 PRD 12.2 的标签管理目标仍保留，当前统计不扩展为批量重命名或删除标签。
