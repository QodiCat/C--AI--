# 权限与敏感信息

server/.env 与 app/.env 均被 Git 忽略；前端 .env 只是公开 API 地址，打包后可读。后端真实密钥、数据库密码、SMTP 密码不能进入提交、文档、截图或测试夹具。
密码使用 bcrypt，注册、重置、修改需输入校验。密码更新撤销所有会话；当前密码错误或验证码错误不能写入数据库。
RequireAuth 限制用户身份，各业务路由同时按 user_id 限制；读取 OSS URI 仅允许当前 Bucket 中当前用户目录，不能接受任意外部资源绕过所有权。
签名 URL 是临时访问授权；禁止日志输出完整签名、查询串、上传凭据或密码哈希。允许记录经清理的服务错误码、请求 ID、目标主机及网络分类。
Bucket 保持私有；浏览器 CORS 来源设置为实际前端地址，只为需要的读方法开放。应用签名接口配置不能替代 Bucket 读权限和 CORS。
[历史更新材料](../docs/更新)只作追溯，曾暴露凭据需轮换；发现泄漏不绕过 push protection。历史重写仅在用户明确授权范围执行，常规任务不主动改写历史。

今日搭配只在用户点击生成时申请前台定位。设备坐标通过已登录 API 请求提交，服务端天气查询及显示取三位小数；不新增用户定位数据库字段，AI 任务保存天气、日期和时区，不保存精确坐标。天气提供方会接收查询坐标；日志不输出请求体。公网部署必须配置 HTTPS，拒绝权限不自动使用虚构位置。
